# PCore — مشروع أندرويد أولي

هذه أول نسخة Android أصلية تجريبية، وليست محرك تشغيل Windows.

## ما الذي يعمل في هذه النسخة؟
- واجهة عربية RTL مع صفحات الرئيسية والألعاب وسطح المكتب والملفات والإعدادات.
- اختيار ملف من الهاتف عبر منتقي Android.
- حفظ قائمة الملفات المستوردة محليًا.
- اختيار صورة كخلفية وحفظ URI الخاص بها لإعادة استخدامها.
- متصفح WebView تجريبي يفتح الإنترنت.
- إعدادات محفوظة محليًا.

## ما الذي لا يعمل بعد؟
- لا يوجد محرك Windows مدمج، لذلك لا يتم تشغيل ملفات EXE أو ألعاب PC.
- لا توجد نتيجة توافق حقيقية للألعاب.
- الخلفيات المتحركة غير مدعومة في هذه النسخة.
- مدير الملفات ما زال بسيطًا، وبعض عناصر سطح المكتب شكلية.

## البناء من الهاتف عبر GitHub Actions
1. أنشئ مستودعًا جديدًا على GitHub من متصفح الهاتف.
2. ارفع محتويات هذا المجلد إلى جذر المستودع، مع الاحتفاظ بمجلد `.github/workflows`.
3. افتح تبويب Actions وفعّل Actions إذا طُلب منك.
4. شغّل `Build PCore APK` باستخدام Run workflow، أو ادفع commit إلى الفرع `main`.
5. بعد نجاح المهمة، افتح نتيجة التشغيل وحمّل artifact باسم `PCore-debug-APK`.
6. فك ضغط ملف artifact، ثم ثبّت `app-debug.apk` على الهاتف. قد يطلب Android السماح بالتثبيت من هذا المصدر.

لا تشارك مفاتيح أو كلمات مرور مع أي شخص. هذا APK تجريبي موقّع بمفتاح debug خاص بعملية البناء.
